# Model credits

The miniature landmarks use Kenney's CC0 City Kit Commercial and City Kit Industrial models.

- https://kenney.nl/assets/city-kit-commercial
- https://kenney.nl/assets/city-kit-industrial

The original palette textures are embedded in these self-contained GLBs. Geometry and colors are unmodified; the scene sets display scale, rotation, and lighting. Both original license files are included here.

Mappings: campus = industrial building D; factory = industrial building H; atrium = commercial building I; tower = skyscraper A; tower-twin = skyscraper E.
